# KHOEPRO WORKSPACE RULES & INSTRUCTIONS

## 1. CSS & Typography Constraints:
- **Font-weight tối đa là 600**: Khi viết hoặc sửa CSS, font-weight cao nhất được phép dùng là `600`. Tuyệt đối không dùng `700`, `800`, `900`, `bold`, `bolder`.
- **Font-family**: Sử dụng font `'Inter', Arial, sans-serif` toàn website, bảo vệ riêng các class FontAwesome icon.

## 2. Git Synchronization:
- Sau mỗi lượt chỉnh sửa, hoàn thiện tính năng hoặc sửa lỗi, tự động commit và push lên nhánh `main` (`origin/main`).
