# FITNADO IMPLEMENTATION PLANS

Thư mục này dùng để lưu trữ các bản kế hoạch thực thi chi tiết (Implementation Plans) cho từng Phase hoặc từng tính năng lớn trong quá trình phát triển dự án FITNADO.

---

## QUY ĐỊNH KHI TẠO PLAN

1. Mỗi Phase phát triển lớn phải có một file kế hoạch riêng biệt:
   * `PHASE-01-FRONTEND-FOUNDATION.md`
   * `PHASE-02-AFFILIATE-SYSTEM.md`
   * `PHASE-03-AI-CONTENT-AND-VIDEO.md`
2. Kế hoạch phải xác định rõ:
   * Mục tiêu cụ thể
   * Danh sách file sẽ thêm mới `[NEW]` hoặc chỉnh sửa `[MODIFY]`
   * Luồng dữ liệu và câu lệnh query
   * Kế hoạch kiểm thử tự động và thủ công (Multi-device viewports)
3. Tuyệt đối không nhét nội dung kế hoạch trực tiếp vào các file mã nguồn PHP.
